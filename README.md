# Ticket Desk

A C# console application for managing internal support tickets.

Built as a small exercise in C# fundamentals, domain modelling, LINQ, and application structure.

## Features

- Create tickets with a title, description, and priority
- List and inspect tickets
- Close tickets
- Escalate or deescalate priority
- Filter by status or priority
- Search by partial title
- Partial ticket-ID lookup
- View ticket statistics

## Requirements

- .NET 10 SDK

## Run

```bash
dotnet run --project src/ticket-desk.display/ticket-desk.display.csproj
